## Overview

LinkShort is a high-performance URL shortening service built with **Nuxt 3**, **Effect Schema**, and **Hasura GraphQL**. Unlike traditional shorteners, LinkShort prioritizes the safety of the end-user by passing every submitted URL through a rigorous 5-layer security verification pipeline. 

The project solves the "Blind Click" problem—where users are redirected to unknown, potentially malicious destinations—by providing real-time threat scores, SSL verification, and phishing detection before a link is even generated.

**Who is this for?**
- **Security Teams:** Organizations requiring internal link management with malware protection.
- **Developers:** Teams needing a robust, type-safe API for programmatically managing short links.
- **Privacy Advocates:** Users who want transparent security reports for every link they share.

## Features

### 🛡️ Security First
- **5-Layer Verification:** Checks URL format, DNS records, SSL/TLS validity, brand impersonation (phishing), and malware databases (Google Safe Browsing).
- **Risk-Based Policies:** Categorizes links into Safe, Low, Medium, High, and Critical risk levels.
- **Rate Limiting:** Sliding window rate limiting via Redis to prevent brute-force attacks and abuse.
- **Domain Banlist:** Global and local domain blacklisting.

### ⚡ Developer Experience
- **End-to-End Type Safety:** Powered by Effect Schema and TypeScript for predictable runtime behavior.
- **GraphQL Integration:** Seamless data orchestration using Hasura and PostgreSQL.
- **API Key Management:** Built-in dashboard to generate and revoke keys for headless usage.

### 📈 User Experience
- **Real-Time Analytics:** Track clicks, referrers, and user agents.
- **PWA Ready:** Installable mobile/desktop experience with offline support.
- **Modern UI:** Responsive dashboard built with Tailwind CSS and Nuxt components.

## Quick Start

### Prerequisites
- Node.js >= 18.x
- Docker and Docker Compose
- A Google Safe Browsing API Key (optional but recommended)

### Installation
1. **Clone the repository:**
   ```bash
   git clone https://github.com/WomB0ComB0/link-shortener.git
   cd link-shortener
   ```

2. **Setup Environment:**
   ```bash
   cp .env.example .env
   # Edit .env with your local database and API credentials
   ```

3. **Launch Infrastructure:**
   ```bash
   docker-compose -f docker/docker-compose.yml up -d
   ```

4. **Install Dependencies & Start:**
   ```bash
   pnpm install
   pnpm dev
   ```

**Expected Output:**
The application will be available at `http://localhost:3000`. You should see the LinkShort landing page.

## Usage & Examples

### Creating a Link (CLI/Curl)
If you have generated an API key via the dashboard:

```bash
curl -X POST http://localhost:3000/api/links/create \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com"}'
```

**Response:**
```json
{
  "code": "a1b2c",
  "shortUrl": "http://localhost:3000/a1b2c",
  "securityScore": "Safe"
}
```

## API Reference

### Auth Endpoints
- `POST /api/auth/register`: Create a new account.
- `POST /api/auth/login`: Authenticate and receive a JWT.

### Link Endpoints
| Endpoint | Method | Params | Description |
| :--- | :--- | :--- | :--- |
| `/api/links/create` | `POST` | `url` (string) | Validates and shortens a URL |
| `/api/links/me` | `GET` | - | Returns links created by the user |
| `/api/[code]` | `GET` | `code` (path) | Redirects to the target URL |
| `/api/links/analytics` | `GET` | `code` (query) | Returns click data for a code |

### Security Endpoints
- `GET /api/security/verify?url=...`: Run the 5-layer pipeline on a URL without creating a link.

## Troubleshooting

| Error | Cause | Solution |
| :--- | :--- | :--- |
| `Rate limit exceeded` | Too many requests from one IP | Wait 60 seconds or increase `RATE_LIMIT_MAX` in config |
| `Insecure Link Blocked` | URL failed the SSL/Phishing check | Use `force: true` (if admin) or use a valid HTTPS URL |
| `Hasura Connection Error` | Docker containers not ready | Run `docker ps` to ensure Hasura/Postgres are running |

## Security & Performance

### Performance Considerations
- **Caching:** Security results are cached in Redis for 1 hour by default to minimize latency on frequent scans.
- **Lazy Loading:** All dashboard analytics components are lazy-loaded to keep initial bundle size small (<100kb).

### Security Notes
- **Middleware:** The `server/middleware/auth.ts` validates every request to protected routes.
- **Verification:** The `verification-pipeline.ts` uses an asynchronous design to ensure that if one scanner (e.g., DNS) hangs, it doesn't block the entire process.
